# Random Number Guessing Game

웹기초프로그래밍 실습 프로그램으로 제작한 랜덤 숫자 맞추기 게임입니다.
HTML, CSS, JavaScript를 활용하여 사용자 입력과 화면 변경, 이벤트 처리 등을 연습합니다.

## 게임 방법

1. 1부터 100 사이의 정수를 입력합니다.
2. 확인 버튼을 누르거나 Enter 키를 누릅니다.
3. 안내되는 크고 작음 힌트를 참고하여 5번 안에 정답을 맞힙니다.
4. 게임이 끝나면 다시 시작 버튼으로 새 게임을 시작합니다.

## 주요 기능

- 1부터 100 사이의 무작위 정답 생성
- 입력값 검사 및 남은 기회 표시
- 입력한 숫자 기록과 힌트 표시
- 정답 및 실패 결과 안내
- 게임 다시 시작

## 실행 방법

프로젝트를 내려받은 뒤 index.html 파일을 웹 브라우저로 엽니다.
외부 글꼴과 초기화 스타일을 불러오려면 인터넷 연결이 필요합니다.

## 파일 구성

- index.html: 게임 화면
- css/style.css: 디자인
- js/script.js: 게임 동작

## 실습 내용

DOM 요소 선택, 변수와 함수, 조건문, 난수 생성, 입력값 검증, 클릭 및 키보드 이벤트 처리를 실습합니다.
